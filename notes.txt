  4. HOW TO RUN - STEP BY STEP
===============================================================================

  STEP 1: Open Terminal in the project root folder
  -------------------------------------------------
  Open VS Code → File → Open Folder → select the "landrecord" folder
  Then open terminal: Ctrl + ` (backtick key)


  STEP 2: Install Frontend Dependencies
  -------------------------------------------------
  Run this command in the terminal (make sure you're in the landrecord folder):

      npm install

  This will read package.json and install:
    - react (v19)
    - react-dom (v19)
    - vite (v8)
    - @vitejs/plugin-react
    - oxlint (linter)

  A "node_modules" folder will be created automatically. DO NOT edit or
  delete this folder manually.


  STEP 3: Start the Frontend Dev Server
  -------------------------------------------------
      npm run dev

  This starts the Vite development server.
  You will see output like:

      VITE v8.x.x  ready in XXXms
      ➜  Local:   http://localhost:5173/
      ➜  Network: http://192.168.x.x:5173/

  Open http://localhost:5173 in your browser.
  The page auto-refreshes when you save any file (Hot Module Replacement).


  STEP 4: Install Backend Dependencies (SEPARATE TERMINAL)
  -------------------------------------------------
  Open a NEW terminal tab (click the + icon in VS Code terminal).

      cd backend
      npm install

  This installs:
    - express (v4)
    - cors


  STEP 5: Start the Backend Server
  -------------------------------------------------
  In the same terminal (inside the backend folder):

      npm start

  OR:

      node server.js

  You will see:

      BhoomiSetu backend running on port 5000

  The backend API is now available at http://localhost:5000

  8. COMMON ISSUES & FIXES
===============================================================================

  Problem: "npm is not recognized"
  Fix:     Install Node.js from https://nodejs.org and restart terminal.

  Problem: "Module not found" or import errors
  Fix:     Delete node_modules folder and package-lock.json, then run:
               npm install

  Problem: Port 5173 already in use
  Fix:     Kill the process using the port:
               npx kill-port 5173
           Or Vite will auto-pick the next available port (5174, etc.)

  Problem: Port 5000 already in use
  Fix:     Kill the process:
               npx kill-port 5000

  Problem: Backend API not connecting from frontend
  Fix:     Make sure both servers are running in separate terminals.
           Check CORS is enabled in server.js (it is by default).

  Problem: Blank white page on localhost:5173
  Fix:     Check the browser console (F12) for errors.
           Usually a missing import or syntax error.

  Problem: Styles not updating
  Fix:     Hard refresh: Ctrl + Shift + R
           Or clear browser cache.
